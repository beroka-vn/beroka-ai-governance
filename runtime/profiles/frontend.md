# Frontend Repository

- The repository consumes the exact self-contained Confluence handoff content
  ID and page version for cross-team work and never requires access to Backend
  team-local repositories.
- Frontend `<Module> — Capability Index` pages link exact Registry rows and
  Confluence content IDs/page versions. The Index remains a team-local
  navigation record; the consumer-facing handoff carries the public contract.
- Jira and Confluence writes remain inside the configured routing unless an
  active integration profile authorizes an exact counterpart.
- Frontend classification alone does not declare a Backend dependency.
