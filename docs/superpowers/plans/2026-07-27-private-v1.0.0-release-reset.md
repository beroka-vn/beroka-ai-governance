# Private v1.0.0 Release Reset Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make authenticated GitHub CLI download the only active onboarding path and publish the first supported private release as `v1.0.0`.

**Architecture:** Reuse the existing launcher and bootstrap implementation unchanged. Update only active version/documentation assertions, then publish the reviewed merge as an immutable annotated tag and verify its asset in isolated environments.

**Tech Stack:** POSIX shell, Git, GitHub CLI

## Global Constraints

- Keep `beroka-vn/beroka-ai-governance` private.
- The supported launcher is `gh release download --repo beroka-vn/beroka-ai-governance --pattern bootstrap.sh --output - | sh -s -- --client CLIENT --non-interactive`.
- The target release is `v1.0.0`.
- Do not rewrite Git history or force-push a tag.
- Do not change connector setup, routing, bootstrap behavior, or OAuth ownership.
- Never request, print, log, or store a developer API token.
- Keep historical specs and plans unchanged.
- Never stage `.beroka-governance.lock` or root `AGENTS.md`.

### Task 3: Publish and verify the reviewed merge

**Files:**
- Read: `VERSION`
- Read: `release/bootstrap.sh.in`
- Create outside repository: temporary rendered `bootstrap.sh`

**Interfaces:**
- Consumes: exact human-merged pull-request commit
- Produces: the sole stable GitHub Release/tag `v1.0.0`

- [ ] **Step 1: Resolve and verify the exact merge**

After the user reports the pull request merged:

```bash
git fetch origin main
release_commit=$(
  gh pr view agent/private-v1.0.0-release \
    --repo beroka-vn/beroka-ai-governance \
    --json state,mergeCommit \
    --jq 'select(.state == "MERGED") | .mergeCommit.oid'
)
test -n "$release_commit"
git cat-file -e "$release_commit^{commit}"
test "$(git show "$release_commit:VERSION")" = v1.0.0
test -z "$(git ls-remote --tags origin \
  refs/tags/v1.0.0 'refs/tags/v1.0.0^{}')"
! gh release view v1.0.0 \
  --repo beroka-vn/beroka-ai-governance >/dev/null 2>&1
```

Expected: the merge contains `v1.0.0`, and no local publication target exists
remotely.

- [ ] **Step 2: Create the local annotated candidate and asset**

```bash
! git show-ref --verify --quiet refs/tags/v1.0.0
git tag -a v1.0.0 "$release_commit" \
  -m "Beroka AI governance package v1.0.0"
asset_root=$(mktemp -d "${TMPDIR:-/tmp}/beroka-v1.0.0-asset.XXXXXX")
git show "$release_commit:release/bootstrap.sh.in" |
sed \
  -e 's/@RELEASE_VERSION@/v1.0.0/g' \
  -e "s/@RELEASE_COMMIT@/$release_commit/g" \
  >"$asset_root/bootstrap.sh"
chmod +x "$asset_root/bootstrap.sh"
sh -n "$asset_root/bootstrap.sh"
test "$(git rev-parse 'v1.0.0^{commit}')" = "$release_commit"
```

Expected: an annotated local tag and syntax-valid asset bound to the exact
merge.

- [ ] **Step 3: Test the exact merge**

```bash
release_checkout=$(mktemp -d \
  "${TMPDIR:-/tmp}/beroka-v1.0.0-checkout.XXXXXX")
rmdir "$release_checkout"
git worktree add --detach "$release_checkout" "$release_commit"
(
  cd "$release_checkout"
  sh -n bin/beroka-governance release/bootstrap.sh.in tests/*.sh
  for test_file in tests/*.sh; do
    sh "$test_file"
  done
)
```

Expected: every shell test passes from the exact merge commit.

  --repo beroka-vn/beroka-ai-governance \
  --verify-tag \
  --latest \
  --title "Beroka AI Governance v1.0.0" \
  --notes "First supported private team release."

Expected: a stable GitHub Release URL.

- [ ] **Step 6: Test authenticated release download**

Use the existing authenticated `gh` session only to download the private

Expected: the asset installs and registers the temporary repository, then

- [ ] **Step 7: Verify final publication state**

```bash
git ls-remote --tags origin 'refs/tags/v1.0.*'
gh release list \
  --repo beroka-vn/beroka-ai-governance \
  --limit 20
gh release download v1.0.0 \
  --repo beroka-vn/beroka-ai-governance \
  --pattern bootstrap.sh \
  --output - |
  grep -F "RELEASE_COMMIT='$release_commit'"
```

Expected: `v1.0.0` is the only `v1.0.x` tag and stable Release, and its asset
embeds the exact merge commit.

Remove only the validated temporary artifacts:

```bash

rm -f "$asset_root/bootstrap.sh"
rmdir "$asset_root"
```
