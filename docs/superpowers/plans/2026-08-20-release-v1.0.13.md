**Spec:** GitHub issue `beroka-vn/beroka-ai-governance#74` and merged PR `beroka-vn/beroka-ai-governance#75`.

- Release version is exactly `v1.0.13`; existing tags remain immutable.
- Release source includes merged PR #75 at commit `3420a88d44383d04dcc0702a581310f149472e31`.
